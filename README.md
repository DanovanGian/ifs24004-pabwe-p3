## Deskripsi
Aplikasi web satu halaman dengan tiga fitur (dipisah tab):
1. **Expense Tracker Pro** — catat pemasukan/pengeluaran, ringkasan saldo, cari/filter/sort.
2. **LinkVault** — simpan tautan favorit dengan validasi URL, kategori, cari/sort.
3. **QuizMaster** — kuis pilihan ganda dengan skor dan high score.

## Teknologi
HTML5, Tailwind CSS (CDN), JavaScript (DOM, localStorage).
